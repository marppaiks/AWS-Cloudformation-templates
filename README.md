# AWS-Cloudformation-templates
Tässä repositoriossa on Cloudformation-mallipohjat, joilla voi luoda VPC-alueen ja IAM-resursseja.

In english: This repository contains CloudFormation templates that create a VPC area and IAM resources.

VPC: VPC + 2 public subnets in their own AZ's
IAM: User for Github integration (Gitworkflow) and Roles for Elastic Beanstalk usage (aws-elasticbeanstalk-service-role, ec2-beanstalk-role)
